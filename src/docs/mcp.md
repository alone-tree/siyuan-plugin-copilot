# MCP (Model Context Protocol) 功能说明

## 概述

MCP（Model Context Protocol）是一种用于在 AI 模型和外部工具之间进行通信的协议。该插件提供了对 MCP 的支持，允许用户连接到外部 MCP 服务器，获取额外的工具、资源和上下文。

## 功能特性

### 1. MCP 服务器管理
- 支持连接到多个 MCP 服务器
- 对每个服务器进行独立的配置管理
- 实时显示服务器连接状态
- 提供测试服务器连接的功能

### 2. 会话级别的 MCP 配置
- 可以为每个聊天会话单独配置 MCP 服务器
- 支持在会话中随时切换 MCP 服务器
- 会话配置会保存到聊天历史中

### 3. MCP 工具集成
- 自动发现并集成 MCP 服务器提供的工具
- 支持工具的自动批准和手动批准模式
- 工具调用结果会显示在聊天界面中

### 4. 设置界面
- 提供直观的 MCP 服务器配置界面
- 支持添加、编辑和删除服务器配置
- 可以为每个服务器配置 API 密钥、超时时间和自定义请求头

## 使用方法

### 1. 配置 MCP 服务器
1. 打开插件设置页面
2. 找到 "MCP 配置" 部分
3. 点击 "添加 MCP 服务器" 按钮
4. 填写服务器信息：
   - 服务器名称：给服务器取一个友好的名称
   - 服务器地址：MCP 服务器的 API 地址
   - API 密钥（可选）：如果服务器需要认证，填写 API 密钥
   - 超时时间：服务器请求的超时时间（毫秒）
   - 自定义请求头（可选）：可以添加额外的 HTTP 请求头

### 2. 使用 MCP 工具
1. 在聊天界面点击工具选择按钮
2. 在工具选择界面中，会显示所有可用的工具（包括 MCP 工具）
3. 选择要使用的 MCP 工具
4. 聊天时，AI 会自动使用选中的工具

### 3. 会话级别配置
1. 在聊天界面点击 MCP 服务器选择按钮
2. 选择要在当前会话中使用的 MCP 服务器
3. 会话配置会保存到聊天历史中

## 技术实现

### 1. MCP 服务管理
使用 `MCPManager` 类管理所有 MCP 服务器连接和工具调用。该类提供了以下功能：
- 服务器连接和状态跟踪
- 工具发现和缓存
- 工具调用执行
- 服务器配置管理

### 2. UI 组件
- `MCPConfigPanel`：MCP 服务器配置界面
- `MCPServerSelector`：会话级别 MCP 服务器选择器
- `ToolSelector`：工具选择组件，支持显示 MCP 工具

### 3. 工具转换
将 MCP 工具格式转换为与现有系统兼容的工具格式，通过 `convertMCPToolToTool` 函数实现。

### 4. 工具调用执行
使用 `executeMCPToolCall` 函数处理 MCP 工具调用，该函数会：
- 查找提供该工具的服务器
- 执行工具调用
- 处理工具调用结果

## 注意事项

### 1. 服务器兼容性
- 确保 MCP 服务器与当前插件版本兼容
- 检查服务器地址和端口是否正确
- 验证 API 密钥是否有效

### 2. 性能考虑
- MCP 工具调用可能会有延迟，取决于服务器响应时间
- 对于长时间运行的工具调用，建议使用异步调用
- 可以通过调整超时时间来优化性能

### 3. 安全性
- 确保 MCP 服务器是可信任的
- 避免在公共网络上暴露敏感信息
- 定期检查和更新服务器配置

## 故障排除

### 1. 服务器连接失败
- 检查服务器地址和端口是否正确
- 验证网络连接是否正常
- 检查服务器是否正在运行

### 2. 工具调用失败
- 检查工具参数是否正确
- 验证服务器是否支持该工具
- 查看服务器日志以获取更多信息

### 3. 性能问题
- 尝试增加超时时间
- 优化工具参数以减少响应时间
- 检查服务器资源使用情况

## 示例

### 连接到 OpenAI MCP 服务器
```
服务器名称：OpenAI MCP
服务器地址：https://api.openai.com/v1/mcp
API 密钥：sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
超时时间：30000
```

### 使用 MCP 工具进行搜索
```
你：帮我搜索关于人工智能的最新研究进展

AI：我将使用搜索工具帮你查找最新的人工智能研究进展。
[工具调用：search_web(query="人工智能最新研究进展")]
[工具结果：搜索返回了5条相关结果，包括论文、新闻和博客文章]

AI：根据搜索结果，以下是人工智能领域的最新研究进展：
1. ...
2. ...
3. ...
```
